# Contract

The single source of truth everyone builds against. Agree on it in hours 0-2.
Anything marked PROPOSED is a suggestion; change it in the first meeting, then tell everyone before changing it again.

- `tables.md`: the database tables and allowed values
- `tools.json`: every MCP tool (name, params, returns)
- `result-format.json`: the structured result a map task returns
- `seed.json`: demo data (used by the brain seed loader, the mock modes, and the dashboard mock)
- `scenarios.md`: what each judge-mode scenario button writes
