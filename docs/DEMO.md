# Demo

## Judge flow (about 60 seconds)
Open the URL or scan the QR code. No login, no install.
1. Run the demo (or press Run map-reduce).
2. Break it: Make Sam hit a limit, Make two agents edit the same file, Teammate goes idle.
3. Poke around: drag a capacity slider, click a task to see why it was assigned.
4. Reset.

## Presenter script (about 3 minutes)
1. Pitch line, then run the demo: one goal, tasks flow out to three teammates.
2. Press Run map-reduce: 12 pieces fan out, the progress bar fills, the merge task unlocks.
3. Trigger the lock collision and show the block.
4. Trigger the limit hit and show the requeue.
5. Switch to Live mode on the laptop: a real Claude Code run, same dashboard.
6. Show the QR code: "try it yourself."

Pitch line: your team's AI coders working as one team, with no collisions, no idle quota, and one shared brain.

## If a judge asks
- "Is it real?" The coordination is real (brain, locks, routing, dashboard). In judge mode only the coding is faked so it's safe, instant, and works for many judges at once. Live mode on the laptop is fully real.
- "Why not just buy a bigger plan?" Bigger plans don't fix collisions or the shared view, and small teams can't always upgrade.

## Before you go on stage
- [ ] Public URL works on venue wifi, on iPhone Safari and Android Chrome
- [ ] Ten simultaneous judge sessions don't interfere
- [ ] Reset works from any state
- [ ] Backup demo video is on the presenter's laptop
- [ ] QR code is printed or on a slide
- [ ] A stranger completed the judge flow without help
